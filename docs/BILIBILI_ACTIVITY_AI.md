# B站投稿活动智能匹配

开关：设置 → 模型服务 → **AI 智能参与 B站投稿活动**。数据库持久化键为
`bilibili.publish.ai_activity_enabled`（存储在 `bilibili.publish` 配置 JSON 内）。
默认值 **false**；适用于手动和自动 B站投稿，且**不覆盖**用户手动填写的
`topic_id`/`mission_id`。

## 行为

1. 在上传成功、正式 `add/v3` 投稿前使用已确定的分区 ID 与视频标题，
   请求创作中心 `/x/vupre/web/topic/type`，以及标题/标签关键词的
   `/x/vupre/web/topic/search`。分别最多 30、20 条，不做全站无限抓取。
2. 获取公开目录 `/x/activity/page/list` 前两页（至多 60 条），只取有效期内、
   与视频主题明显相关的活动；普通话题最多保留 65 个，为活动单独预留候选名额，
   避免大量无关推荐把活动挤掉。**公开活动 `id` 不是 `mission_id`**。
   模型只见标题、简介、摘要和归一化候选，不会获取 B站 Cookie 或 AI Key。
3. 复用“自动处理”选中的 OpenAI 兼容模型，第一轮最多挑出三个候选项。
   - **普通话题**：创作中心再次查询并严格匹配名称和 `topic_id`；即使没有
     `mission_id`，也可单独提交 `topic_id`，**不会自动填入任何活动任务 ID**。
   - **投稿活动**：公开活动 `id` 与投稿 `mission_id` 必须严格分开。核实
     公开目录中的活动名称、开始/结束时间和进行中状态，并寻找同名且唯一的
     创作中心 `topic_id` 和真实 `mission_id`；结合创作中心官方规则与
     可用的活动详情进一步检验版权、投稿附加条件和资格。不猜测 `sid`。
     无法验证规则或有必须报名、必须改标题/简介等额外条件时不自动参加。
4. 第二轮 AI 在已验证选项中按视频主题、原始来源和规则决定使用哪个普通话题
   或活动；普通话题无需报名，不能只因不是奖励活动就忽略它。
   若 AI 仅因“不是活动”拒绝已经核实且明显相关的话题，使用保守话题回退，
   不采纳模型输出的数值 ID。活动具有先报名、白名单、粉丝门槛等
   无法确认的账号条件时拒绝自动参与。YouTube 等第三方来源即使被误标自制，
   也只会在明确允许转载的活动中尝试参与。公开 API 无法保证奖励资格。
5. 结果保存在稿件发布记录 `response_json.activity`，包含类型
   （`topic`/`activity`）、选择理由、候选与核验计数、拒绝原因和真实 ID。
   发布成功后将实际提交的标签、`topic_id` 和 `mission_id` 写回投稿
   `meta_json`，避免界面一直显示 AI 选择前的旧快照；也写入只含非敏感 ID
   的发布日志。
   AI 不可用、接口错误、资格不明确、候选不足或非 OpenAI 模型时跳过活动匹配，
   **保持原投稿行为**，不自动重复提交已经发出的 `add/v3` 请求。

## 边界

- 活动规则、账号参与资格和奖励资格未必能通过公开 API 完整核验；
  AI 的判断不是 B站的正式资格确认。
- `x/activity/page/list` 与创作中心未必一致；日期与奖励条件须以活动详情为准。
- 2026-11-13 实际登录环境验证：公开列表 `x/activity/page/list` 可返回活动，
  但对其中的列表 `id` 调用 `x/activity/subject/info?sid=<id>` 返回
  `code=-404`。**禁止将列表 id 直接当成详情 sid、mission_id 或 topic_id**。
  新版在缺少独立 sid 时使用公开目录的活动时间和名称，与登录的创作中心精确同名、
  唯一的真实 `topic_id`/`mission_id` 和参与规则交叉核验。无法确认资格则不参与。
  例如明日方舟双狼活动有真实 mission_id，但要求指定标题后缀、简介提及活动方
  等附加条件，不能据此将普通 YouTube 转载视频直接登记为参赛作品。
- 默认投稿模板标签为空，不再固定追加 `videoroll` 或 `视频分享`。
  历史模板仅含一个旧品牌词或“视频分享”时，读取时兼容为空；其他手动标签保留。
  自动/直接投稿首先使用 AI 生成的内容标签和手动标签。若全部为空，才请求 B站创作中心
  `/x/vupre/web/tag/recommend` 获取 **普通标签**（区别于话题/活动），过滤自动推荐中的
  无关品牌词及第三方来源的“原创”“首发”等可能误导的标签。若依然为空或接口不可用，
  最终仅填入 `视频分享` 兜底，满足实际投稿至少一个标签的要求。
- 本功能不代替原有的幂等投稿、速率限制、稿件审核机制。
- 不支持把 Index-Translate 这类仅提供翻译接口的服务当作通用 JSON 选择模型；
  使用该模式会跳过活动匹配。

## 主要测试

`tests/test_bilibili_activity_selector.py` 和 `tests/test_bilibili_activity_settings.py`
验证 ID 映射、手动覆盖保护、时效过滤、失败降级、转载限制和默认开关行为。
