# ffplayout / VideoRoll 媒体导入边界

V2 资源与 ffplayout 视频库存采用显式链接，不允许通过任意文件路径删除已排播媒体。

## 已实现

- 对 V2 已登记并具备 SHA256 的渲染视频进行跨设备安全导入，优先 hardlink，跨文件系统回退复制。文件命名为「译名-任务短 ID-P1/P2.mp4」，直接位于 VideoRoll 目录。
- 复制使用临时文件、数据落盘同步和原子 create-if-absent，禁止已有目标被静默覆盖；导入后重新计算目标 SHA256。
- 以 vr2_playout_links 保存资产、频道、路径、传输类型和状态。对源资产增加 owner_type=playout 的注册引用，避免普通终态 GC 删除仍用于播控的源文件。
- P2 导入需先经过相同任务的成功 V2 YouDub 运行与成品绑定校验；普通字幕 P1 不需要配音。
- 显式取消链接只撤销源资产引用并标记 detached，不删除 ffplayout 物理目标文件，避免破坏当前正在播放的节目。
- 不复制整个原版播放队列数据库和 Web 控制台，以防破坏既有播控。

## 未完成

- ffplayout 的真正节目单插入、修改、激活、暂停以及频道管理 API 尚未与 V2 原生 API 完全对接。
- 正在播出的文件与 ffplayout 内部数据库的双向状态核对尚未完成，因此不能依据数据库单一引用关系自动删除播控目录。
- 渲染素材来自其他 Worker 的到期资源回收压力和 ffplayout 跨挂载路径仍需真实测试。

安全原则：导入文件不等于播放节目，不得在前端显示已激活/播放中，除非 ffplayout 服务端真实确认。
