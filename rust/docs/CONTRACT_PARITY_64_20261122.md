- 本测试只能判断每个已映射入口在隔离 Rust 进程中的请求行为和未登录拒绝行为。
- 正向请求仅验证返回状态/基础 JSON 结构；未完成 Python 生产响应字段、错误码、状态迁移的逐项差分。

- 不对生产账号执行真实投稿、删改或会话操作。
